# EPSILON: Extrasolar Planetary Systems Imaging Library Of Notebooks

Library of shared code, tools, and notebooks from STScI's [Extrasolar Planetary Systems Imaging Group](https://www.stsci.edu/stsci-research/research-groups/extrasolar-planetary-systems-imaging-group)

EPSILON is primarily focused on providing short, self-contained notebooks and scripts for 
general use by the Extrasolar Planetary Systems Imaging Group (EPSIG). These resources
will be heterogenous in nature, and therefore this repository is not intended to be an 
installable package. 

## General Guidelines
- Submission and use of notebooks and scripts is open to all members of the EPSIG.
- Notebooks and scripts should be contained in a subdirectory with a descriptive name, 
and should include a README.md file that describes the purpose of the notebook or script, the lead author, as well as any dependencies or requirements for running it.
- Maintenance of notebooks and scripts will be performed on a best-effort basis. If you have questions or issues, contact the lead author of the notebook or script you are trying to use.
